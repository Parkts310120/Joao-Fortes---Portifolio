## Engineering approach

I care about:

- clear domain boundaries;
- reproducible environments;
- tests that protect behavior;
- SQL and data integrity;
- explicit error handling;
- CI/CD;
- logs and observability;
- security boundaries;
- documenting trade-offs and limitations.

I prefer adding infrastructure when the problem justifies it rather than adding tools only to make a stack look bigger.

## AI-assisted engineering

I use AI tools heavily for research, decomposition, prototyping, debugging, test design, review and documentation.

My workflow is:

```text
define the problem
  -> inspect evidence
  -> research/prototype
  -> validate
  -> test
  -> debug
  -> review
  -> decide
```

AI assistance does not replace understanding the behavior, testing the result, or taking responsibility for the final technical decision.
